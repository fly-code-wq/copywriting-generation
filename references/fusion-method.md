# 文案融合与交叉创新方法 (fusion-method.md)

把"若干条参考素材"变成"原创候选"的核心思路。

> 三段式拆解（hook / 论据 / CTA）+ 重组 + 变异，是文案改写的黄金三角。

---

## 整体流程

```
[参考素材 K 条]
   │
   ▼
[STEP 1: 结构拆解]   抽取每条的 hook / 论据 / CTA 三段
   │
   ▼
[STEP 2: 交叉重组]   把"参考 A 的 hook" + "参考 B 的论据" + "参考 C 的 CTA" 拼出新骨架
   │
   ▼
[STEP 3: 变异与本地化]  把骨架套到当前场景关键词 + 用户画像语言风格
   │
   ▼
[STEP 4: 多样性生成]  生成 N 条候选，互相之间风格/hook 公式不同
   │
   ▼
[STEP 5: 去重校验]   scripts/dedupe.py 过滤与参考/候选之间雷同者
   │
   ▼
[输出 N 条候选]
```

---

## STEP 1 — 结构拆解

每条参考文案拆成 3 段：

| 段 | 作用 | 拆解要点 |
|----|------|---------|
| **Hook（钩子）** | 前 1-2 句抓住注意力 | 数字、痛点、反差、悬念、身份 |
| **Body / 论据** | 中间展开 | 场景细节 / 数据 / 个人体验 / 转折 |
| **CTA（行动召唤）** | 结尾引导互动 | 评论区告诉我 / 收藏 / 点赞 / 关注 / 购买 |

**示例拆解**（小红书）：
```
原文：
"雨后的西湖真的太治愈了 🍃
站在断桥上听雨声，整个人都安静下来。
雨滴打在荷叶上，氛围感拉满。
📍 杭州西湖 · 断桥
#西湖 #杭州旅行 #治愈系风景"

拆解：
  Hook: "雨后的西湖真的太治愈了 🍃"  ← 场景+情感
  Body: 站在断桥上听雨声 / 雨滴打在荷叶上  ← 细节
  CTA:  📍 杭州西湖 · 断桥 + 标签       ← 地点+tag
```

---

## STEP 2 — 交叉重组

3 条以上参考，可自由组合：

| 候选 N | Hook 取自 | Body 取自 | CTA 取自 |
|--------|-----------|-----------|----------|
| 1 | A | B | C |
| 2 | B | C | A |
| 3 | C | A | B |
| 4 | A+B（混合） | — | C |
| 5 | 自创钩子 | A+B 综合 | 自创 |

多样性原则：
- N ≥ 5 时，至少 3 种不同 hook 公式
- 至少 2 种不同情绪（温暖 / 幽默 / 高级感等）
- 至少 1 条与参考"反差极大"（如参考都偏温暖，反差款应冷幽默或专业）

---

## STEP 3 — 变异与本地化

把骨架套到当前场景：

1. **场景关键词替换**：把"断桥""雨声""荷叶"等换成用户场景里的真实元素。
2. **人称本地化**：参考原文用"我"，候选可换"我" / "姐妹们" / "谁懂啊"等。
4. **emoji 与句式按平台风格卡调整**（见 `references/platform-styles.md`）。
5. **用户画像对齐**：
   - `fav_words` 里出现的词要适当用 1-2 个
   - `emoji_density` 决定 emoji 多寡
   - `sentence_length` 决定每句字数
   - `punctuation_pref` 决定结尾标点

**示例**（用户画像：fav_words=["绝绝子","氛围感"], emoji_density=0.8）：
```
参考骨架：  "雨后的西湖真的太治愈了 🍃"
本地化后：  "家人们谁懂啊！雨后的西湖直接氛围感拉满 🍃✨"
```

---

## STEP 4 — 多样性生成 Prompt 模板

给 LLM 的提示词模板（中文版）：

```text
你是一位擅长{平台}文案的创作者。
用户场景：{scene}
用户偏好（来自画像）：
{profile_summary}

平台风格约束：
- emoji 密度 ≈ {emoji_density}
- 字数范围 {min_chars} ~ {max_chars}
- 标签数量 {meta_tag_count}
- 钩子公式：{hook_formula}
- 禁用词：{banned_words}

参考素材（用于借鉴，绝不能照抄）：
[1] {ref1.text}
[2] {ref2.text}
[3] {ref3.text}

任务：生成 {n} 条候选文案，要求：
1. 每条都要 hook / body / CTA 三段齐全
2. 多样性：3 种以上不同 hook 公式
3. 不与参考素材相似度 > 0.5（jaccard）
4. 直接输出 5 条文案，每条前用 [1] [2] 编号
5. 不要解释，不要写"好的，以下是..."
```

---

## STEP 5 — 去重校验

生成完后**必须**跑 `scripts/dedupe.py`：

```bash
python scripts/dedupe.py \
  --candidates candidates.jsonl \
  --against assets/seed_corpus.jsonl \
  --out survivors.jsonl \
  --edit-thresh 0.40 --jaccard-thresh 0.55
```

阈值参考：
- edit_thresh = 0.40（编辑距离 / 长度 ≤ 40% 视为雷同）
- jaccard_thresh = 0.55（3-gram Jaccard ≥ 0.55 视为雷同）

> 阈值的选择要兼顾"严格防抄"与"保留改写空间"。MVP 推荐用上面的默认；如要更严，可调低；如发现误杀好候选，调高。

任何超过阈值的候选直接丢弃或大幅改写。

## Few-shot 示例

**输入**：scene="今天去了西湖，雨后空气特别好"，platform="xiaohongshu"，n=3

**候选输出**：
```
[1] 家人们，雨后西湖真的氛围感拉满 🍃
站在断桥上，整座城市都慢了下来。
雨滴打在荷叶上，空气里有夏天的味道。
📍 杭州西湖 · 断桥
#西湖 #杭州旅行 #氛围感 #治愈系

[2] 谁懂啊！西湖一下雨就直接绝绝子 ✨
3 个超出片的小众机位分享给你
📍 北山街 / 杨公堤 / 茅家埠
#西湖拍照机位 #雨后西湖 #小众旅行地

[3] 上周踩雷：这 5 个西湖机位现在去刚刚好 🌧️→☀️
雨后 30 分钟是黄金时间。
#西湖旅行攻略 #雨后 #2024 最新
```

多样性体现：候选 1 偏情感，候选 2 偏机位/分享，候选 3 偏攻略/时间窗口。

## 常见错误 ❌

1. **直接照抄参考的开头 + 改几个词** → 必须打散结构
2. **全部候选用同一种 hook 公式** → 至少 3 种
4. **emoji 忽略平台规则** → 小红书需要密集，朋友圈几乎不用
5. **没有 CTA** → 至少 50% 候选要有互动引导
6. **忽略用户画像** → fav_words 完全没用上，画像就没意义了
